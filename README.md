# GKC Demos Repository

Public repository for a quick access to the most recent demo builds of Game Kit Controller

Press the Green button "Code" and press "Download Zip" to get all the files, unzip it and you can access to each demo folder to unzip the main zip file of each folder to play each demo.

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------

这是一个公开的代码仓库，方便您快速获取 Game Kit Controller 的最新演示版本（demo builds）。

请点击绿色的“Code”按钮，然后选择“Download Zip”下载所有文件；解压后，您可以进入各个演示版本的文件夹，解压其中的主压缩包，即可运行相应的演示。
